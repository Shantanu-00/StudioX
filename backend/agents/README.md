# StudioX agents (Strands on Bedrock AgentCore)

Two AgentCore runtimes in one AgentCore CLI project (this directory is the project root):

| Runtime | Entry | Payload (`backend/CONTRACTS.md` section 4) |
| --- | --- | --- |
| `analyst` | `app/analyst/main.py` | `mode`: `segment`, `lenses`, `curate`, `map`, `answer` |
| `coviewer` | `app/coviewer/main.py` | `action`: `refine`, `ask` |

```
backend/agents/
  agentcore/            agentcore.json (both runtimes), aws-targets.json, cdk/ (generated by `agentcore create`)
  app/analyst/          main.py, pyproject.toml, iam-policy.json, symlinks: sxagents -> ../../sxagents,
  app/coviewer/           studiox_core -> ../../../shared/python/studiox_core (the CLI copies symlink targets)
  sxagents/             shared agent code: llm (models, record/replay), search, guards, lenses, analyst, coviewer
  run_local.py          the local runner (Bedrock only, no deploy)
  tests/                pytest, offline (recorded fixtures in tests/fixtures/*.rec.jsonl)
```

The project layout is what `agentcore create --name analyst --project-name studioxagents --framework
Strands --model-provider Bedrock --memory none --build CodeZip --language Python --skip-install`
generates (non-interactive), edited to hold two runtimes on Python 3.13.

## How it works

- **segment** (Sonnet 5.5): topical segments, speaker names, genre. Clips under 90 s stay one segment.
- **lenses**: an orchestrator agent (Haiku 5.5) calls lens agents as tools (`people_lens`,
  `claims_lens`, `burst_lens`, `protocol_lens`, `events_lens`), each at most once (BudgetGuard
  hook). Every lens is a fresh `Agent` with `structured_output_model` (Pydantic) and emits TV widgets
  with evidence snapped to transcript lines. Response: `{candidates: [{lens, widget, salience,
  reason, audit}], recap, rejected, lensCalls}` (`rejected`, `lensCalls`, `audit` are additive).
  - people (Sonnet) -> `dossier`. Tool `wikipedia_lookup` (REST summary, descriptive User-Agent).
    Image only when the Commons `extmetadata` licence is CC0 / PD / CC BY / CC BY-SA.
  - claims (Sonnet) -> `claim` with `verdict` + `sources`. Fact-check flow is a plain bounded loop
    (not a Strands Graph: two of its four steps are deterministic code): query -> search -> stance per
    source (Sonnet) -> `studiox_core.verdict.decide_verdict` -> at most 2 refined searches.
  - burst (Haiku) -> `entity_list` (3+ named items within 20 s, enforced in code).
  - protocol (Haiku) -> `protocol`; events (Haiku) -> `timeline` (3+ timed events, enforced in code).
- **curate** (Sonnet): picks widget ids, writes moments and 2-3 suggested questions (a question time
  inside a line moves to the line's end).
- **map** (Sonnet, `sxagents/mapper.py`): the Map author (CONTRACTS section 9). Input: transcript,
  segments, the shown cards (ids, types, headlines, verdicts, evidence and their parts with times),
  the curator's moments and questions, and `pinned` questions. The agent decides eligibility,
  category and layout and writes groups, nodes, edges, sims (`night`, `growth`) and questions.
  Code snaps each node to the transcript line it comes from, attaches each pinned question to the
  node on screen at its time, and `studiox_core.map.validate_map` has the final say (bounds, counts,
  verdicts copied only from referenced claim cards, sim params clamped, eligibility). Response:
  `{explore, problems, questions}`, where `questions` is the curator's plus the map's (with
  `mapNode`), the list the answer step runs over.
- **answer** / **ask** (Haiku): transcript up to `t` only, tools `read_transcript` (clamped) and
  `web_search` (max 2). `cites` are seconds (line starts before `t`), as the TV expects.
- **refine** (Haiku): caption + at most one `entity_list` / `protocol` / `timeline`, evidence <= `t`.

**Search:** `GATEWAY_URL` set -> AgentCore Gateway Web Search connector (`WebSearch` MCP tool) through
`bedrock_agentcore.tools.WebSearchClient` (MCP over SigV4; the gateway must use AWS_IAM inbound auth).
Otherwise Nova 2 Lite web grounding (`nova_grounding` system tool, URLs from `citationsContent`). If
that fails, claims come back UNVERIFIED with no sources.

**Rules in code:** SpoilerGuard (hook clamps `read_transcript` times; the prompt only ever holds
`before(t)`; tools clamp again; cites at or after `t` dropped), CitationGuard (`guards.cite_guard`:
a URL must be in this invocation's search ledger), BudgetGuard (hook: tool calls per agent call and
per tool; ledger: searches per invocation; fact-check: 3 searches per claim, 4 claims per segment).

**Prompt caching:** the shared transcript/brief is the first system block followed by a `cachePoint`.
Claude only caches prefixes over its minimum (about 1k tokens), so 37 s clips mostly hit the cache
inside the tool loop, not across lenses.

## Environment

| Var | Default | Use |
| --- | --- | --- |
| `SONNET_MODEL_ID` / `HAIKU_MODEL_ID` / `NOVA_MODEL_ID` | `us.anthropic.claude-sonnet-5-5` / `us.anthropic.claude-haiku-5-5` / `us.amazon.nova-2-lite-v1:0` | Models |
| `SX_REGION` | `us-east-1` | Bedrock region (`AWS_REGION` is ignored on purpose) |
| `BUCKET` or `BUCKET_PARAM` | `BUCKET_PARAM=/studiox/bucket` in agentcore.json | Where `transcriptKey` is read |
| `GATEWAY_URL` | unset | Gateway MCP endpoint for the Web Search Tool |
| `MEMORY_ID` | unset | coviewer writes ask turns to AgentCore Memory |
| `SX_RECORD` / `SX_REPLAY` | unset | Record every model/search/wiki call to JSONL / replay offline |

Payloads may carry the transcript inline as `transcript` (used by `run_local.py` and tests).

## Run locally (restricted creds are enough: Bedrock only)

```bash
uv run --python 3.13 backend/agents/run_local.py package --transcript backend/data/transcripts/science-ep42.json --out /tmp/science-ep42.json --media-id science-ep42
uv run --python 3.13 backend/agents/run_local.py package --transcript backend/data/transcripts/crime-case104.json --out /tmp/crime-case104.json --question "12|Does the ping break his alibi?"
python3 backend/scripts/seed_demo.py local all   # demo episodes + cameo examples into src/analysis/packages
uv run --python 3.13 backend/agents/run_local.py ask --transcript backend/data/transcripts/science-ep42.json --t 12 --question "Is the 37% from a real study?"
uv run --python 3.13 backend/agents/run_local.py refine --transcript backend/data/transcripts/crime-case104.json --t 20
uv run --python 3.13 --with pytest --with strands-agents --with bedrock-agentcore pytest backend/agents/tests -q
```

## Deploy (owner, admin credentials)

```bash
cd backend/agents/agentcore/cdk && npm install && cd ../..      # once
agentcore package                       # optional: builds both CodeZip artifacts locally
agentcore deploy                        # both runtimes (CDK)
agentcore status                        # runtime ARNs
aws ssm put-parameter --overwrite --region us-east-1 --name /studiox/agents/analyst/arn --value <analyst ARN>
aws ssm put-parameter --overwrite --region us-east-1 --name /studiox/agents/coviewer/arn --value <coviewer ARN>
agentcore invoke --runtime coviewer '{"action":"ask","sessionId":"s-0123456789abcdef0123456789abcdef0","mediaId":"science-ep42","t":12,"question":"Is the 37% real?"}'
```

`app/*/iam-policy.json` (wired as `additionalPolicies`) grants Bedrock invoke, `s3:GetObject` on
`studioxcore-*/transcripts/*` and `packages/*`, `ssm:GetParameter` on `/studiox/bucket`,
`bedrock-agentcore:InvokeGateway` and (coviewer) `bedrock-agentcore:CreateEvent`. To use the Web Search
Tool, add `{"name": "GATEWAY_URL", "value": "https://<gateway-id>.gateway.bedrock-agentcore.us-east-1.amazonaws.com/mcp"}`
to both runtimes' `envVars` in `agentcore/agentcore.json`.

> Copy `agentcore/aws-targets.example.json` to `agentcore/aws-targets.json` and set your AWS account ID (that file and `.cli/` are git-ignored).
